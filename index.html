📚 家教行程规划助手

粘贴家教单原文 → 自动识别时间 / 薪资 / 地址 → 调用高德地图计算通勤 → 排出每周最优行程与收入

1基础设置

🚇 只坐地铁(步行接驳自动计算)

💡 高德 Key 免费申请:打开 console.amap.com → 注册登录 → 应用管理 → 创建应用 → 添加 Key,服务平台选「Web服务」即可。Key 只保存在你本机浏览器里,不会外传。📱 手机上高德解析不了地址?勾选「手动通勤模式」,给每个单填上「到家分钟」,不用高德也能出完整方案。
📦 数据只存在你自己浏览器的本机存储里:每个人打开各存各的、互不可见;换手机或换浏览器前,点下方「导出我的数据」备份,到新环境「导入」即可恢复。

2我的空闲时间(可选)

每个时段格式如 10:00-12:00, 19:00-22:00,可多段用逗号分开;留空表示该天无空闲。生成方案时,没写上课时间的候选单会自动排进这些时段(自动剔除已接单占用的时间),以整周通勤最短为目标。

3已接的家教单(固定)

🔒 你的已接单和空闲时间已经预填好,并自动保存在本机浏览器。平台新发来的单子请粘贴到下方「候选新单」区,不会改动这里;方案里点「✅ 采用新单」可把选中的新单转为已接单。⏰ 生成方案时会尝试把已接单时间微调(前后各 1 小时以内)以缩短整体通勤,调整建议只显示在结果里,不修改卡片原始时间。

4候选新单(粘贴平台新发的单,已接单不受影响;再粘贴新单会清掉上一批候选)

🧠 智能选单:从这批单里挑最优一单自动勾选并生成方案——没写时间的单先排进你的空闲时段、自动选最近出发点;定时的单按家长要求时间段算通勤;通勤最短的赢,差距30分钟以内改选薪资最高的单。

🗺每日行程

课与课之间会自动比较「直接前往」和「先回家再出发」哪种更划算;所有路线均为纯地铁(含步行接驳)。⏰ 没写时间的候选单会被自动安排到空闲时段(最短通勤);「一周N次」的候选自动挑 N 个空闲日(各天同时段);已接单时间会在±1小时内自动微调,调整与安排建议显示在上方提醒区。🚶 排时遵守正常作息:上课和出门都在 8:00-19:00 内,课与课之间的预留时间 = 两单地址之间的通勤时间 + 15 分钟余量。
